## Deployment

Throughtout the process of creating this project I alternated through using Git Pages and the Live Server extention on VS Code. Live Server was for dynamic updating, and Git Pages was where the final would be uploaded, so it would be important to test them intermediately.

### scripting.js

A constant at the top of the file is defined twice. This is because Git Pages accessses links in different ways and so I needed to append the repository name at the end. Otherwise, I would need to truncate it because Live Server reads the direct folder path. Make sure to change the file when needed.
